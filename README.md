## 🛠️ 本地预览方式

本项目为纯原生静态前端，零外部 CDN，完全离线可用：

### 方法一：双击直接运行
直接在访达（Finder）中双击 `index.html` 即可在默认浏览器中打开。

### 方法二：使用 Python 静态服务器（推荐）
在终端中进入项目目录运行：
```bash
python3 -m http.server 8000
```
在浏览器访问：`http://localhost:8000`

## 🚀 部署至 GitHub Pages 详细指南

只需几个简单步骤，即可免费获得一个可以在微信、QQ、浏览器中分享给朋友的专属链接：

### 第一步：在 GitHub 上新建仓库
1. 登录 [GitHub](https://github.com/)。
2. 点击右上角 `+` -> **New repository**。
3. 仓库名填写为 `wxj`（或任何你喜欢的名字），选择 **Public**（公开），不要勾选初始化 README 等选项，点击 **Create repository**。

### 第二步：推送本地代码到 GitHub
在当前项目根目录下打开终端，执行以下命令：

```bash
# 1. 将所有修改添加到暂存区
git add .

# 2. 提交本地版本
git commit -m "feat: 升级为5关黄金节奏版（陈九源考研上岸压轴）"

# 3. 推送到远程仓库
git push origin main
```

### 第三步：开启 GitHub Pages 服务
1. 进入 GitHub 仓库页面，点击上方的 **Settings**（设置）。
2. 在左侧菜单栏中找到 **Pages**（在 Code and automation 分类下）。
3. 在 **Build and deployment** 下的 **Source** 选择 **Deploy from a branch**。
4. 在 **Branch** 下拉菜单中选择 `main` 分支，目录保持 `/ (root)`，点击 **Save** 保存。
5. 等待 1~2 分钟刷新页面，顶部将出现访问链接：
   > *Your site is live at https://<你的用户名>.github.io/<仓库名>/*

## ✏️ 如何修改人物姓名与文案

如果想换人名或微调某题的措辞，直接编辑 `js/config.js` 文件：

```javascript
window.GAME_CONFIG = {
  // 1. 修改被提问者姓名（最终关会自动在问题中金色高亮显示）
  targetName: '陈九源',

  // 2. 修改任意关卡的问题或选项文字
  level1: { ... },
  level2: { ... },
  level3: { ... },
  level4: { ... },
  level5: {
    question: '{name}，究竟能不能考研上岸？', // {name} 会自动替换为 targetName
    answerA: '一战成硕，必须狠狠上岸！',
    answerB: '这……要不先问问肖秀荣？'
  }
};
```
修改完成后保存，直接刷新网页或重新推送到 GitHub 即可自动更新！
